# Uso de IA en Programación Funcional · 2026 S2

Dashboard de 57 formularios de la encuesta de uso de IA en la cursada. Incluye las distribuciones de las 15 preguntas, filtros, búsqueda de respuestas abiertas y exportación de datos.

`index.html` contiene el código y las transcripciones. Funciona sin dependencias ni servicios externos, tanto localmente como en GitHub Pages. El PDF escaneado no forma parte de esta publicación.

Los conteos conservan las selecciones múltiples y las particularidades del recorrido. Los campos de lectura dudosa se identifican en el dashboard. Las menciones en textos abiertos se cuentan mediante palabras clave y no representan una clasificación manual de opiniones.
